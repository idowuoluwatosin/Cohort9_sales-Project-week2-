# Cohort 9 Sales Data Cleaning and Analysis

## Project Overview
This project focuses on cleaning, validating and analysing a sales dataset using Excel and SQL. The goal was to identify data quality issues, handle missing revenue values appropriately, and prepare the dataset for reliable analysis.

## Tools Used
- Microsoft Excel
- MySQL Workbench
- SQL

## Project Files
- **data:** Original and cleaned sales datasets.
- **excel:** Spreadsheet containing formulas and summaries.
- **sql:** Seven SQL queries used for data exploration and analysis.
- **screenshots:** Query outputs and evidence of SQL work.
- **documentation:** Cleaning log and data quality report.

## Cleaning Process
- Identified missing revenue values.
- Reviewed transaction types, including refunds.
- Checked and assigned appropriate data types.
- Preserved missing revenue as NULL where applicable.
- Performed validation checks after cleaning.

## SQL Analysis
The SQL queries were used to retrieve records, investigate refund transactions, sort revenue values and perform data quality checks.

## Limitations
Missing revenue values limited the completeness of revenue calculations and comparisons. Missing figures were not arbitrarily replaced with zero or estimated values.

## Conclusion
The project provided practical experience in data cleaning, SQL querying, data validation and documentation. It demonstrates the importance of data quality before performing business analysis.
